## 🚀 Upload Instructions

### Step 1 — Create the special profile repo
> The repo name **must exactly match** your GitHub username.

```
Repo name: Dev-moe-kyawaung
(or whichever account you're uploading to)
```

### Step 2 — Upload files via GitHub Web UI

1. Go to `github.com` → **New Repository**
2. Name it exactly your **username** (e.g. `Dev-moe-kyawaung`)
3. Set to **Public**
4. Check **"Add a README file"**
5. Click **Create repository**
6. Click **Add file → Upload files**
7. Drag and drop **all files** from this folder
8. Commit with message: `✨ Add premium profile README V65`

### Step 3 — Enable GitHub Actions

1. Go to **Settings → Actions → General**
2. Select: **Allow all actions and reusable workflows**
3. Save

### Step 4 — Verify

Visit `github.com/Dev-moe-kyawaung` — your profile should now show the premium README!
